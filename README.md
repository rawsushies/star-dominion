# Star Dominion

An interstellar kingdom grand-strategy simulator. Rule a young civilisation, expand across a procedurally generated galaxy, manage a real production economy, build fleets, negotiate with AI kingdoms, and decide your own path to galactic power.

Work in progress — see `GAME_DESIGN.md`, `ARCHITECTURE.md` and `DEVELOPMENT.md` (coming with milestone 1).

```bash
npm install
npm run dev     # play in the browser
npm test        # simulation tests
```
